## About me

I design and build educational products with game mechanics: I work out the scenario and economy, design the interface, assemble a working prototype, and take it all the way to a live application with a database, AI features, and automated deploys. 20 working prototypes in my portfolio — every one opens by link.

## Flagship projects

### 1. Kanikuly with ONE! — a full-cycle camp platform
A gamified system for managing summer camps: 11 themed shifts, in-game economy (NEO-coins, XP, 90 cards), DISC profiles, missions, and PDF reports for parents. React + Supabase (PostgreSQL, RLS), automated deploy via GitHub Actions.

[**Open demo →**](https://crazynordic19871987.github.io/kanikuly-s-one/) · [Code](https://github.com/CrazyNordic19871987/kanikuly-s-one)

[![Kanikuly with ONE!](https://api.microlink.io/?url=https%3A%2F%2Fcrazynordic19871987.github.io%2Fkanikuly-s-one%2F&screenshot=true&meta=false&embed=screenshot.url)](https://crazynordic19871987.github.io/kanikuly-s-one/)

### 2. ONE! Profile v2 — an AI mentor for the student
An RPG profile for camp participants: avatars, levels, XP, progress — plus personalised feedback generated via the OpenAI API. React + TypeScript + Tailwind + Supabase.

[**Open demo →**](https://crazynordic19871987.github.io/one-profile-v2/) · [Code](https://github.com/CrazyNordic19871987/one-profile-v2)

[![ONE! Profile v2](https://api.microlink.io/?url=https%3A%2F%2Fcrazynordic19871987.github.io%2Fone-profile-v2%2F&screenshot=true&meta=false&embed=screenshot.url)](https://crazynordic19871987.github.io/one-profile-v2/)

### 3. Nashville Number Guitar — an offline app in a single HTML file
An interactive trainer for the Nashville Number System on guitar: 12 keys, 17 progressions with live transposition, modes and pentatonics, 49 licks, a Web Audio API metronome, and a bilingual interface. One `index.html` — no build, no dependencies, no internet.

[**Open demo →**](https://crazynordic19871987.github.io/nashville-number-guitar/) · [Code](https://github.com/CrazyNordic19871987/nashville-number-guitar)

[![Nashville Number Guitar](https://api.microlink.io/?url=https%3A%2F%2Fcrazynordic19871987.github.io%2Fnashville-number-guitar%2F&screenshot=true&meta=false&embed=screenshot.url)](https://crazynordic19871987.github.io/nashville-number-guitar/)

### 4. Student Psychology Feedback Generator — applied LLM
Asynchronous generation of psychological feedback from student surveys using a local model (Ollama + Mistral). Python, pandas, AIOHTTP, with error handling and resumable progress.

[**Code →**](https://github.com/CrazyNordic19871987/student_psychology_feedback_generator)

[![student_psychology_feedback_generator](https://api.microlink.io/?url=https%3A%2F%2Fgithub.com%2FCrazyNordic19871987%2Fstudent_psychology_feedback_generator&screenshot=true&meta=false&embed=screenshot.url)](https://github.com/CrazyNordic19871987/student_psychology_feedback_generator)

### 5. SberAutoSubscription — Data Science (DA + ML + DE)
Final project of the "Introduction to Data Science" course: exploratory analysis and hypothesis testing (1.86M sessions), an ML model (Random Forest) with a Flask API, and a data pipeline with a database.

[**Open demo →**](https://crazynordic19871987.github.io/WebAutoSubscription---DE-DA-ML/) · [Code](https://github.com/CrazyNordic19871987/WebAutoSubscription---DE-DA-ML)
